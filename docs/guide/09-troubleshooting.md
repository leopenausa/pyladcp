# 9 · Troubleshooting

!!! note "Draft pending"
    This chapter is planned but not yet written. Outline: a symptom → cause → fix
    catalogue, including:

- "indexed 0 casts from 0 files" — wrong/empty paths (unset `$B`).
- A station missing from the index — its CTD cast is missing (cannot be anchored).
- `SHARED-MASTER` flags — two anchors claiming one deployment file.
- Velocity skipped: no up-looker / unsupported coordinate frame.
- Whole-profile offsets vs a reference — bottom-track quality, reference window.
- Wrong-looking directions — magnetic declination, compass offset.
- Excel missing from exports — `pip install "pyladcp[export]"`.
